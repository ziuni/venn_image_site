세 원 이미지 밴다이어그램 - 3차 버전

실행 방법
1. index.html 파일을 다운로드합니다.
2. 파일을 더블클릭해 Chrome, Edge, Safari 등 브라우저로 엽니다.
3. 업로드 상자에 이미지 파일을 끌어다 놓거나 상자를 눌러 파일을 선택합니다.

주요 기능
- 세 원 공통 크기 조절 / 원별 개별 크기 조절 모드
- 타원 가로·세로 크기 개별 조절
- 가로·세로 비율을 유지하며 함께 확대·축소하는 옵션
- 원 사이 간격과 원 제목 조절
- 이미지 파일 드래그 앤 드롭 업로드 및 다중 업로드
- 업로드한 이미지 목록 / 목록에서 선택
- 이미지 이동, 크기 조절, 뒤로 보내기, 삭제
- 원만 초기화 (이미지의 위치·크기·목록 유지)
- 전체 초기화 (이미지도 함께 삭제)
- PNG 이미지로 저장

참고
- 업로드한 이미지는 브라우저 안에서만 처리됩니다.
- 페이지를 새로고침하거나 닫으면 작업 내용이 저장되지 않으므로, 완료 후 PNG로 저장해 주세요.

세 원 이미지 밴다이어그램

실행 방법
1. index.html을 Chrome, Edge, Safari 등의 브라우저로 엽니다.
2. 이미지 업로드 상자에 파일을 끌어다 놓거나 눌러서 추가합니다.
3. 이미지 전체 삭제를 누르면 업로드한 이미지만 모두 삭제됩니다. 원의 크기, 간격, 제목은 유지됩니다.

GitHub Pages 배포
- index.html을 저장소 최상위 폴더에 업로드합니다.
- Settings > Pages > Deploy from a branch > main > /(root)를 선택합니다.

참고
- 이미지는 현재 브라우저에서 로컬로 처리됩니다.
- 새로고침하면 작업 중인 이미지 배치 상태는 보존되지 않습니다.

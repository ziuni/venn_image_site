세 원 이미지 밴다이어그램

사용 방법
1. index.html 파일을 Chrome, Edge, Safari 등 최신 브라우저에서 엽니다.
2. '이미지 추가하기'를 눌러 이미지 파일을 선택하거나, 이미지 파일을 작업 영역에 끌어다 놓습니다.
3. 이미지를 드래그해 원 안이나 교집합 영역으로 옮깁니다.
4. 선택한 이미지의 모서리 손잡이 또는 오른쪽 크기 슬라이더로 크기를 조절합니다.
5. 오른쪽 설정에서 원 크기, 원 사이 간격, 원 제목을 바꿉니다.
6. 'PNG 이미지로 저장'을 누르면 현재 작업 화면이 PNG로 저장됩니다.

참고
- 별도 설치나 서버 없이 index.html 하나로 실행할 수 있는 단일 페이지 초안입니다.
- 선택한 이미지는 이 브라우저 안에서 처리되며 외부 서버로 업로드되지 않습니다.
- 브라우저 탭을 닫으면 현재 편집 내용은 저장되지 않으므로, 작업이 끝나면 PNG로 내보내세요.
